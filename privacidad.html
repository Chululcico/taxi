2. Datos que recogemos

Podemos recoger y tratar los siguientes datos personales:

  • Datos identificativos: nombre, apellidos, número de teléfono, dirección de email.
  • Datos del servicio: dirección de origen, destino, fecha y hora del trayecto.
  • Datos de navegación: dirección IP, tipo de navegador, páginas visitadas (mediante cookies).

3. Finalidad del tratamiento

Los datos recogidos se utilizan para:

  • Gestionar y confirmar las reservas de taxi solicitadas.
  • Contactar con el cliente para coordinar el servicio.
  • Mejorar la experiencia de usuario en el sitio web.
  • Cumplir con obligaciones legales y fiscales.

4. Legitimación

La base legal para el tratamiento de tus datos es:

  • La ejecución de un contrato de servicio (reserva de taxi).
  • El consentimiento expreso del usuario al contactarnos o aceptar cookies.
  • El interés legítimo en mejorar nuestros servicios.

5. Conservación de los datos

Conservamos tus datos durante el tiempo necesario para prestar el servicio y cumplir con nuestras obligaciones legales (mínimo 5 años según la normativa fiscal). Los datos de navegación se conservan 12 meses.

6. Derechos del usuario

Tienes derecho a:

  • Acceder a tus datos personales.
  • Rectificar datos inexactos.
  • Solicitar la supresión de tus datos.
  • Limitar u oponerte al tratamiento.
  • Portar tus datos a otro responsable.

Para ejercer tus derechos, contáctanos en info@taxibadalonaaeropuerto.com o por teléfono 600 00 00 00.

7. Destinatarios de los datos

No cedemos datos a terceros salvo obligación legal. Los datos de las reservas no se comparten con terceros para fines comerciales.

8. Medidas de seguridad

Aplicamos medidas técnicas y organizativas adecuadas para proteger tus datos personales frente a accesos no autorizados, pérdida o alteración.

9. Derecho de reclamación

Si consideramos que no hemos tratado tus datos correctamente, puedes presentar una reclamación ante la Agencia Española de Protección de Datos (www.aepd.es).

Para cualquier consulta, puedes contactarnos a través de 600 00 00 00 o por WhatsApp.
